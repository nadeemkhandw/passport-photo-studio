# Passport Photo Studio Web Application

High-precision Passport & Visa Photo Studio Web Application built with React, TypeScript, Tailwind CSS, HTML5 Canvas, and jsPDF.

## Features
- **Multi-Photo Batch Upload**: Upload multiple photos simultaneously with copy quantity counters.
- **Biometric Crop & Alignment Modal**: Aspect-ratio locked crop box with biometric head oval overlay, eye alignment line, 90° rotation, and brightness/contrast sliders.
- **Global Passport & Paper Presets**: Supports US (2x2"), EU/UK (35x45mm), China (33x48mm), Canada (50x70mm), India, Japan, Stamp photo, A4, Letter, 4x6" Photo paper, etc.
- **Cut Lines & Margin Controls**: Solid, dotted, corner crosshairs, row/column gap sliders, and page margin controls.
- **300 DPI PDF & PNG Export**: High-resolution print export + direct 1:1 millimetric scale browser printing.

## Running Locally
```bash
npm install
npm run dev
```
